# Linear Algebra Journey

A 17-week structured journey through linear algebra — from intuition to implementation. Built around the principle: **video → hand calculation → code → explanation**. Every concept is implemented from scratch before reaching for `np.linalg`.

> *"What I cannot create, I do not understand."* — Richard Feynman

---

## 🎯 Goals

- Build deep, intuitive understanding of linear algebra (not just formulas)
- Implement core operations from scratch before using NumPy/SciPy abstractions
- Produce one Jupyter notebook per week as a public deliverable
- Lay the mathematical foundation for graduate study in Statistics & Data Science

## 🛠️ How I'm Learning — Quality Principles

1. **One topic per week.** No skipping ahead. Depth over breadth.
2. **Four steps, never skipped:** video → hand calculation → code → written explanation.
3. **One notebook per week**, pushed to GitHub. Portfolio grows daily.
4. **Milestone test at the end of each phase.** No advancing without passing.
5. **Math by hand first, library second.** `np.linalg.inv` only after solving by hand.
6. **Karpathy's rule:** *"If you don't understand something, implement it from scratch."*
7. **One hour of review every week.** Math is forgotten without repetition.
